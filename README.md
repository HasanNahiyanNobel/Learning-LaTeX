# Learning LaTeX

This is my playground for learning LaTeX—started by following
[the tutorial](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes)
of Overleaf.

Additionally, although old,
[A Beginner’s Guide to LaTeX](https://www.cs.princeton.edu/courses/archive/spr10/cos433/Latex/latex-guide.pdf)
by David Xiao seems like a good reference point.
